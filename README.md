## Sobre o projeto

O **Solar System Explorer** é uma aplicação web desenvolvida com **React** para apresentar os planetas do Sistema Solar e informações sobre missões espaciais em uma interface visual e organizada.

O projeto permite praticar a construção de interfaces com componentes reutilizáveis, a renderização de dados e a organização de uma aplicação front-end.

## Funcionalidades

- Visualização dos planetas do Sistema Solar.
- Exibição de cartões com informações sobre missões espaciais.
- Interface construída com componentes React.
- Aplicação disponível online por meio do GitHub Pages.

## Como executar localmente

**Pré-requisitos:** Node.js 18 ou superior e npm.

```bash
# Clone o repositório
git clone https://github.com/suelemmacedo/Solar-System-Project.git

# Acesse a pasta
cd Solar-System-Project

# Instale as dependências
npm install

# Inicie a aplicação
npm start
```

A aplicação será aberta em `http://localhost:3000` (ou na porta indicada pelo terminal).

## Build e publicação

Para gerar a versão de produção:

```bash
npm run build
```

Para publicar no GitHub Pages:

```bash
npm run deploy
```

O deploy utiliza a branch `gh-pages`. O arquivo `public/.nojekyll` impede o processamento do conteúdo pelo Jekyll, permitindo que os arquivos compilados do React sejam servidos diretamente.
